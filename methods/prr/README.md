# hs-prr: Pose-Restore-and-Redecide (PRR)

Original RoboMetaHarness recovery mechanism (run `rtcfpp-20261101`, round-6 RECOVERY proposal P1), implemented as a
HarnessStudio v2 **controller** method for openpi `pi0_fast_libero` on vla-eval LIBERO (`null: shadow`). Fidelity
`tf_variant` (Backtrack 2610.32941v1 controller with its trained trigger replaced by a public proprio rule; FastHarness
waypoint return without its reviewer). It consolidates and supersedes r4c-p2-retrace and r2-P2; it is the first and only
screened recovery-family unit of the session. Primary category `execution_monitoring`; mechanism ids
`retrace_retry_on_stall` (primary), `pigey_route_verify_recover` (analogy only).

| Entry | Role |
|---|---|
| `prr` | candidate: route A (confirmed runaway) + route B (late stall) |
| `prr-hold` | DEVELOPMENT-ONLY control: same rules, zero-motion rows |
| `prr-ortho` | DEVELOPMENT-ONLY norm-matched control: reversal position rows rotated +-90 deg about world z (public coin) |

Normative semantics: `hs_prr/planner.py` (docstring) and the card disclosures (`hs_prr/paper.yaml`, generated by
`scripts/make_cards.py`). Deviation D1 (ortho coin from public inputs instead of the case index) and interpretations I1/I2
are listed there for critic acknowledgement.

## Files
- `hs_prr/planner.py`: trigger/checkpoint/guard state machine (pure; also drives the C3 table).
- `hs_prr/controller.py`: the controller (native decisions = `ctx.policy.sample(1)` + 5 rows, one `ctx.execute` per row).
- `hs_prr/geometry.py`: rotation helpers (world-frame log map, tilt, benchmark gripper discretization).
- `scripts/replay_table.py`: C3 tables from the package over the 80 dev identity traces and S2 (streamed).
- `scripts/witness.py`: evaluator hooks: `q-recur` (C6 + W1), `determinism` (C9), `tier2-null` (C10); outcome-blind loader.
- `scripts/mutation_check.py`: every listed sabotage must make the tests fail.
- `tests/`: planner units, active path through the real in-process stack (scripted runaway/stall/cancel/age cap/custody/
  horizon/quiet; baseline, shadow null, prr, hold, ortho), witness scoring, C3 lock.
