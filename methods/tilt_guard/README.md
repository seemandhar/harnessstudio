# tilt-guard (HarnessStudio v2 method package, rtcfpp-20261101 round 1)

New training-free mechanism; not a reproduction of any cited paper. One composite `action_op` for openpi
`pi0_fast_libero` on vla-eval LIBERO (5 actions per call, `quat_no_antipodal: true`, z-score serving):

1. **Z** decode-failure substitution: the exact openpi zero chunk (all rows identical, dims 0-5 = actions mean + state,
   gripper = actions mean, tol 1e-4) detected on the NATIVE chunk is replaced by the previous decision's post-G rows
   5-9 with the latched gripper; at most 2 consecutive substitutions (tail, hold), then native passthrough.
2. **G** saturation-gated rx band guard: `hs_band_guard` (band-guard v1.0, frozen, imported read-only).
3. **B** boundary tilt envelope: after the first proprio-detected subtask boundary (release after a >= 4-decision
   hold), for 150 steps, when the gripper approach axis is tilted > 55 deg from vertical, remove the tilt-increasing
   part of every executed rotation command and add a bounded restoring rotation.

Entry points (one frozen card each, `hs_tilt_guard/paper_<v>.yaml`, generated by `scripts/make_cards.py`):
`tilt-guard-gb`, `tilt-guard-gbz`, `tilt-guard-gz`, `tilt-guard-z` (component sets) and the development-only controls
`tilt-guard-gyaw` (yaw-matched B control), `tilt-guard-gbzsign`, `tilt-guard-gzsign`, `tilt-guard-zsign` (random-sign Z).

Install: `uv pip install --python harnessstudio/.venv/bin/python --no-deps -e harnessstudio/methods/tilt_guard`
(hs-band-guard must already be installed). Checks: `pytest harnessstudio/methods/tilt_guard/tests`,
`hs verify tilt-guard-gb --tier 0` / tier 1, CPU replay `scripts/replay_dev.py --run runs/rtcfpp-20261101 --out OUT`.
Rules, scalars and disclosures: `hs_tilt_guard/action_op.py` docstring and the cards. Evidence and freeze manifest:
`runs/rtcfpp-20261101/implementation/tilt-guard/`.
