# hs-tube-steer-vfb (tube-steer-vfb, tube-steer-vfb-ortho)

Pre-registered A5 variant TV of rtcfpp-20261101 round 5 (P2): a self-contained copy of the frozen `hs-tube-steer`
1.0.0 plus one fallback. When the public instruction has no success memory (LIBERO-10 t8), the tube at each decision is
the decision-time gripper z-axes of the k = 8 SigLIP-nearest rows of the frozen visual memory (RTCF S2 PREP descriptors,
127 S2 successes at init 10-29). Otherwise the code path is T's (TV == T bitwise; `scripts/replay_tv_vs_t.py`).

- Rule: `runs/rtcfpp-20261101/reviews/a5-decision.json` p2_ruling.exact_rule; cards generated by `scripts/make_cards.py`.
- Encoder: pinned in the card params (URL, revision, pooling, weights sha, pinned files); /health checked once per
  episode, failure raises (infrastructure failure). Requires the SigLIP service at http://127.0.0.1:8149.
- `tube-steer-vfb-ortho` is a development-only control (C6 capped ortho law).
- Tests: `tests/` (CPU; one live-service test skips when :8149 is down). Offline checks: `scripts/replay_tv_vs_t.py`,
  `scripts/t8_retrieval_stats.py`, `scripts/mutation_checks.py`.
